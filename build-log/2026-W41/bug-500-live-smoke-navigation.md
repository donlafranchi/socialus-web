### bug #500 — the overnight live smoke failed on one navigation

Run 37659539842 (10:30 PT, production, `96b0ea6`): 55 passed, 59 skipped by design (routes with no stable live address), **1 failed**: `ownerBusiness › root`, `page.goto("/")` at 1280px timed out at 30s waiting for the `load` event. The 390px pass on the same screen read 347 lines of the right content; production answered `/` in 0.2–0.8s when checked afterwards; nothing leaked and no screen errored. Not reproducible without the `BUILDER_SEED` secret. Cause: `load` waits for every external resource a page pulls in (the map's, at 1280px), so one slow third-party request can fail a healthy screen. Fix: `src/lib/smoke/navigate.ts` waits for the document, retries a timed-out navigation once, and records a second timeout as a problem on that route instead of throwing (so the other screens still run); an HTTP error is reported once and never retried. Tests first (6).
