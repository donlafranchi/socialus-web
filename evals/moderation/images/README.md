# Eval images

**As of 2026-10-19** · Source: hand-written · Maintained by: hand (set by regen-doc-inventory from the last commit date; the owner confirms on next edit)

Fixtures for the moderation harness (`npm run moderation:eval`). Never served to members, never uploaded to the app: they are read from disk and sent only to the model under test.

`LICENCES.json` is the record per picture (checked by `src/lib/moderation/eval-cases.test.ts`). Pictures with licence `synthetic` are generated by `scripts/moderation-make-images.ts`. The real photos, all from Wikimedia Commons:
